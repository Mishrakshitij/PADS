# Original release

`RL_PADS.zip` is the original code archive previously stored at the repository
root (Git commit `fcc071f9f9f4c0bfae74b8e68b8674f52ed72a7e`). Its bytes are unchanged.

SHA-256: `a70ae0908b417e862398d42087b939d185b6780d9502fae960ec9e64e1dce84a`.

The maintained implementation is in `src/pads/`; the archive provides a reference
for the original prototype, sample assets, and exploratory experiment logs.
Those logs are not a reproduction of the publication's result tables.

The supplied `RL_PADS_Data.zip` remains a local, ignored input archive. Its six
CSV files are published under [`datasets/`](../datasets/), with checksums and
row-preserving media shards recorded in the dataset manifest.
