# Attribution and license scope

The dialogue text derives from the [MultiDoGO dataset](https://github.com/awslabs/multi-domain-goal-oriented-dialogues-dataset).
Its upstream license is the **Community Data License Agreement – Permissive,
Version 1.0**. The original [license](MultiDoGO-LICENSE.txt) and Amazon
[attribution notice](MultiDoGO-NOTICE.txt) are included unchanged.

The PADS release includes additional prediction fields and retains the supplied
CSV export, including its source anomalies. Media is divided into three CSV
parts for distribution; removing the extra headers reconstructs the original
file byte for byte. Details and checksums are in the [dataset documentation](../datasets/README.md).

These upstream notices apply to the underlying MultiDoGO data. They do not
establish a license for the PADS code, added annotations, or manuscript. The
original PADS code archive did not include a software license; this maintenance
release does not assign one on the authors' behalf. Cite PADS and MultiDoGO when
using the corpus and obtain any additional permission required for your use.
